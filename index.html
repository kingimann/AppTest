What's inside

  • 2D renderer (Canvas 2D) and 3D renderer (WebGL: lighting, fog, blob shadows)
  • Touch controls: virtual joystick, jump/fire buttons, drag and tap. Keyboard on desktop
  • Arcade physics: static, dynamic and kinematic bodies, triggers, gravity, platformer grounding
  • Behaviors: move, platformer, spawner, shooter, collectible, hazard, goal, patrol, camera follow, custom scripts…
  • Game flow: title screen, score, lives, best score saved on the device, game over, win, pause
  • Editor: add objects, drag, pinch-zoom/orbit, inspector, undo, saved projects, one-file HTML export

Use it from code

import { Engine, Scene } from './engine/pocket.js';

const engine = new Engine();
engine.start(() => {
  const s = new Scene({ mode: '2d', settings: { title: 'MY GAME', joystick: true } });
  s.add({ name: 'Player', tags: ['player'], x: 200, y: 500,
          shape: { type: 'circle', r: 20, fill: '#33f0ff' },
          behaviors: [{ type: 'move', speed: 260 }] });
  s.add({ x: 200, y: 200, shape: { type: 'star', w: 40, h: 40, fill: '#ffd23d' },
          behaviors: [{ type: 'collectible', score: 10 }] });
  return s;
});
